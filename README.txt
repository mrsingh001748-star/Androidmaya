MAYA - ANDROID APP (फ़ोन-कॉल जैसी बातचीत)
===========================================

यह ऐप क्या करता है
- "कॉल शुरू करें" दबाइए और हिंदी/अंग्रेज़ी में बोलिए।
- माया जवाब का पहला वाक्य बनते ही बोलना शुरू कर देती है (पूरे जवाब का इंतज़ार नहीं)।
- बोलने के बाद अपने आप फिर सुनती है। हर बार बटन दबाना नहीं पड़ता।
- "याद रखो मुझे चाय पसंद है" बोलने पर वह बात याद रख लेती है।

आपको दो चीज़ें चाहिए
1) Android Studio (मुफ़्त, कंप्यूटर पर)
2) Anthropic API key और उसमें थोड़े credits (पैसे)

----------------------------------------------------------------
STEP 1: Android Studio लगाइए
----------------------------------------------------------------
- https://developer.android.com/studio से Download करके Install कीजिए।
- पहली बार खोलने पर जो पूछे, सब "Next/Finish" करते जाइए। यह बड़ा डाउनलोड है,
  इंटरनेट अच्छा रखिए।

----------------------------------------------------------------
STEP 2: प्रोजेक्ट खोलिए
----------------------------------------------------------------
- ज़िप को Extract कीजिए, "AndroidMaya" फ़ोल्डर बनेगा।
- Android Studio में File > Open > "AndroidMaya" फ़ोल्डर चुनिए।
- "Trust Project" आए तो Trust दबाइए।
- नीचे Gradle का काम चलेगा। पहली बार 5 से 15 मिनट लग सकते हैं, रुकिए।
- "Install missing SDK / Android 14 (API 34)" जैसा कुछ आए तो Install/Accept दबाइए।

----------------------------------------------------------------
STEP 3: फ़ोन तैयार कीजिए
----------------------------------------------------------------
- फ़ोन में Settings > About phone > "Build number" पर 7 बार टैप कीजिए।
- Settings > Developer options > "USB debugging" चालू कीजिए।
- फ़ोन को USB से कंप्यूटर से जोड़िए। फ़ोन पर "Allow USB debugging?" आए तो Allow कीजिए।

----------------------------------------------------------------
STEP 4: ऐप चलाइए
----------------------------------------------------------------
- Android Studio में ऊपर हरा Play (Run) बटन दबाइए। ऊपर की सूची में आपका फ़ोन दिखना चाहिए।
- ऐप फ़ोन में अपने आप लग जाएगा।
- (दूसरा तरीका) Build > Build Bundle(s)/APK(s) > Build APK(s)। बनी APK फ़ोन में भेजकर
  Install कर लीजिए।

----------------------------------------------------------------
STEP 5: API key
----------------------------------------------------------------
- https://console.anthropic.com पर account बनाइए।
- Billing में थोड़े credits डालिए (कितने चाहिए और कीमत क्या है, यह उसी पेज पर देख लीजिए)।
- "API Keys" में नई key बनाइए (sk-ant-... से शुरू होती है)।
- ऐप खोलकर ऊपर वाले खाने में key चिपकाइए। यह सिर्फ़ आपके फ़ोन में सेव होती है।
- key किसी को मत दीजिए। APK किसी को भेजें तो पहले key वाला खाना खाली कर दीजिए।

----------------------------------------------------------------
STEP 6: बात कीजिए
----------------------------------------------------------------
- "कॉल शुरू करें" दबाइए। पहली बार माइक की अनुमति आएगी, Allow कीजिए।
- "सुन रही हूँ… बोलिए" दिखे तो बोलिए।
- कॉल खत्म करने के लिए वही बटन दबाइए।

----------------------------------------------------------------
अगर दिक्कत आए
----------------------------------------------------------------
- "इस फ़ोन में सुनने की सेवा नहीं मिली": Play Store में "Speech Recognition & Synthesis
  from Google" अपडेट/Install कीजिए।
- हिंदी आवाज़ नहीं बोलती: Settings > Language/System > Text-to-speech > Google engine >
  भाषा Hindi जोड़िए।
- "API key गलत है": key दोबारा चिपकाइए, आगे-पीछे खाली जगह न रहे।
- "credits नहीं हैं": console.anthropic.com पर Billing में credits डालिए।
- स्क्रीन बंद होने या दूसरे ऐप में जाने पर कॉल अपने आप रुक जाती है।
  कॉल के दौरान स्क्रीन चालू रहती है।
- Gradle में कोई लाल एरर दिखे तो उसका पूरा मैसेज या स्क्रीनशॉट भेज दीजिए।
